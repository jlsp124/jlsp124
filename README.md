# Jovan Pahal

## Projects

- **[Atlas](https://github.com/jlsp124/atlas)** — a course companion I use for my own classes, with assignments, notes, search, progress tracking, and Japanese review.
- **[RECPLACE Professional Centre](https://github.com/jlsp124/recplace)** — the website for a commercial development in Prince George, including construction updates, leasing information, and an interactive building view.
- **[Mucho Cash Helper](https://github.com/jlsp124/mucho-cash-helper)** — a small checkout helper I made for cash and e-transfer orders at work.
